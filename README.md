## About This Portfolio

This is my personal QA and automation engineering portfolio.

It showcases practical testing projects, automation frameworks, API testing, defect analysis, test documentation, and risk-based quality engineering.

My approach focuses on:

- Prioritizing business-critical scenarios and high-risk defects.
- Designing positive, negative, and boundary test cases.
- Validating both API responses and system behavior.
- Identifying unexpected failures and gaps in requirements.
- Building maintainable, reusable test automation.
- Documenting findings with reproducible evidence.

**The goal is not simply to execute tests, but to understand what can fail, why it matters, and how to verify system quality effectively.**

## Running the Website Locally

Clone the repository:

```bash
git clone https://github.com/quality-krl/PersonalSite.git
cd PersonalSite
```

Install dependencies:

```bash
npm ci
```

Start the development server:

```bash
npm run dev
```

Open:

http://localhost:3000

Build for production:

```bash
npm run build
```
